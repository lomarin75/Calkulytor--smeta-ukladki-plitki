## Структура калькулятора

### 3 шага (wizard)
1. **Площадь** — поле ввода + слайдер (1–100 м²)
2. **Вид укладки** — 5 категорий с табами:
   - Керамическая плитка (7 вариантов)
   - Керамогранит (11 вариантов, до 60 см / более 60 см)
   - Широкоформатный керамогранит (5 вариантов)
   - Мозаика (2 варианта)
   - Кабанчик (2 варианта)
3. **Доп. услуги** — чекбоксы:
   - Подрезка плитки (500–800 ₽/пог.м)
   - Грунтование (200 ₽/м²)
   - Цементная затирка (600–1000 ₽/м²)
   - Эпоксидная затирка (1000–1500 ₽/м²)
   - Запил торцов (2000 ₽/пог.м)
   - Сверление отверстий (1000 ₽/шт)
   - Плинтус из плитки (1500 ₽/пог.м)
   - Ревизионный люк (1000 ₽/шт)
   - Доплата за фартук с мебелью (800 ₽/м²)

### Смета
- Шапка: «„АМ Ремонт": смета на проведение работ» + дата/время + итоговая сумма
- Расшифровка по позициям с ценами за единицу
- Скачивание PDF автоматически через html2pdf.js (без окна печати)
- Дисклеймер об ориентировочности

### Форма заявки «Записаться на замер»
- Поля: Имя, Телефон (с +7 по умолчанию)
- Отправка в VK через PHP-скрипт `vk-send.php` на хостинге Beget

## Логика расчёта

```
Итого = Площадь × Базовый тариф + Σ(Доп. услуги × Кол-во)
```

Базовый тариф зависит от категории и типа укладки. Доп. услуги считаются по площади или по погонным метрам/штукам.

## Конфигурация (в `script.js`)

```javascript
const CONFIG = {
    VK_SEND_URL: '/vk-send.php'  // PHP-скрипт на хостинге
};
```

## Что умею делать (типовые задачи)

- **Добавить тип укладки** → новая запись в `PRICES` в `script.js`
- **Добавить категорию** → новая секция в `PRICES` + таб в HTML
- **Изменить цены** → правка значений `price` в `PRICES`
- **Скачивание PDF** → функция `downloadPDF()` в `script.js` (html2pdf.js)
- **Доп. услуги** → новый объект в `EXTRAS` + блок в HTML
- **Сменить палитру** → правка токенов в `:root` в `style.css`
- **Изменить VK** → `CONFIG.VK_SEND_URL` в `script.js`, токен и ID в `vk-send.php`
- **Изменить шаги/тексты** → правки в `index.html`
- **Изменить формулу** → логика в функции `calculate()` в `script.js`
- **Деплой на сервер** → загрузить `index.html` + `script.js`, инкрементировать `?v=N` для сброса кэша
