# Калькулятор-смета от АМ-ремонт

Онлайн-калькулятор предварительной стоимости укладки плитки для мастеров и заказчиков.
![скриншот страницы калькулятора_1](images/Снимок%20экрана%202026-07-25%20214131.png)

## Назначение

Калькулятор рассчитывает ориентировочную стоимость работ по укладке плитки на основе введённых данных: площади, вида укладки и дополнительных услуг. Результат — подробная смета с возможностью скачивания в PDF и отправки заявки на замер.

## Возможности

- **3-шаговый мастер**: площадь → вид укладки → доп. услуги
- **5 категорий плитки**: керамическая, керамогранит (3 размера), мозаика, кабанчик
- **Динамический расчёт**: итоговая сумма обновляется без перезагрузки
- **Подробная смета**: расшифровка по каждой позиции с ценами за единицу
- **Экспорт в PDF**: скачивание сметы одним кликом (через html2pdf.js)
- **Заявка на замер**: форма сбора имени и телефона (с +7) с отправкой в VK
- **Адаптивный дизайн**: корректно отображается на мобильных устройствах

## Установка и запуск

Калькулятор — статический сайт. Для запуска достаточно открыть `index.html` в браузере.

При обновлении файлов на сервере рекомендуется инкрементировать версию в `index.html` (`?v=2`, `?v=3` и т.д.), чтобы сбросить кэш браузера.

```bash
# Локальный сервер (опционально)
npx serve .
# или
python -m http.server 8000
```

## Интеграции

### VK
Заявки отправляются в **VK** через PHP-скрипт на хостинге Beget.

**Настройка:**
1. VK-группа → Настройки → Работа с API → Создать ключ доступа с правами «Сообщения»
2. PHP-скрипт `vk-send.php` загружен на `https://ri1616ul.beget.tech/vk-send.php`
3. Токен VK и ID получателя прописаны в `vk-send.php`


**Хостинг:** Beget (0000.beget.tech)
